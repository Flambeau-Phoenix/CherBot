# Bundled icon subset

These outline SVGs are copied from Tabler Icons, copyright Paweł Kuna, under the MIT license in `LICENSE.txt`. Only icons used by CherBot are bundled. The originals retain their paths, view boxes and stroke widths.

The `icon()` DOM helper displays them as CSS masks so active, inactive and disabled states inherit the surrounding text color. Icons are decorative; navigation and controls retain visible text labels. No icon package, CDN or frontend build step is required.

Material UI's MIT notice for the elevation shadow values in `app.css` is included at `../assets/MUI-LICENSE.txt`.
